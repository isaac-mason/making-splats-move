# dust

Dust motes drifting through a sunlit Gaussian-splat greenhouse: the room is a static capture, and the motes are a stateless procedural splat generator in the same collection. Drawn by [Radix][radix] on three.js's `WebGPURenderer`.

## Assets

The greenhouse came from [Marble](https://marble.worldlabs.ai/) (World Labs'
3D-world generator).

[radix]: https://sparkjs.dev/radix/
